# Changelog

All notable changes to this product vision are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-11-22

### Added

- [0001](decisions/0001-free-and-open-source-on-a-public-website.md) Free, open source and offered on a public website
- [0002](decisions/0002-play-your-own-music-and-watch-it-come-alive.md) Visitors play their own music and watch it come alive
- [0004](decisions/0004-your-music-and-choices-stay-in-your-browser.md) Your music and choices stay in your browser and survive updates
- [0006](decisions/0006-anyone-can-add-a-visualization-in-one-file.md) Anyone can add a visualization by writing one file
- [0008](decisions/0008-a-recorded-clip-looks-exactly-like-the-screen.md) A recorded clip looks exactly like the screen
- [0009](decisions/0009-synced-lyrics-in-every-visualization.md) Synced lyrics appear in every visualization
- [0010](decisions/0010-arrange-the-picture-in-layers.md) Visitors arrange every picture in layers
- [0011](decisions/0011-an-optional-ai-hears-each-instrument.md) An optional AI hears each instrument
- [0012](decisions/0012-developers-get-extra-settings-on-request.md) Developers get extra settings on request
- [0013](decisions/0013-the-app-never-changes-your-choices.md) The app never changes your choices

### Deprecated

- [0003](decisions/0003-open-in-fullscreen-on-start.md) Open in fullscreen on start: replaced by auto-play in 1.5.6
- [0005](decisions/0005-offer-the-original-visualizations.md) Original visualizations: retired for Pulsar in 2.0.0
- [0007](decisions/0007-an-ai-tunes-the-picture-for-you.md) An AI tunes the picture for you: removed in 3.6.0, no real target to learn from
