# Glossary

| Term              | Meaning, in user words                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| Studio            | The one page where you play music and watch it visualized.                                      |
| Configurator      | The settings panel (<kbd>Tab</kbd>).                                                            |
| Playlist          | The track panel (<kbd>Shift</kbd> + <kbd>Tab</kbd>).                                            |
| Visualization     | One look for the music, picked from a list.                                                     |
| Pulsar            | The default visualization.                                                                      |
| Spectrogram       | The oldest visualization, brought back in 2.4.0.                                                |
| Stems             | The visualization that draws each instrument on its own.                                        |
| Layer             | One piece of the picture; reorder it, change its opacity and blend mode.                        |
| Background        | The bottom layer: a colour or your own image, with an optional pulse, shake or parallax effect. |
| Lyrics            | The top layer: the song's words, synced to the music.                                           |
| Stem separation   | The AI that splits a song into drums, bass, vocals, guitar, keys and the rest.                  |
| Stem              | One of those instrument parts.                                                                  |
| Model             | One trained version of that AI, named after a star (Vega, Lyra).                                |
| Smoothness        | The live readout of how smoothly the page draws.                                                |
| Notice            | The warning on the main screen that says what is wrong and what to change.                      |
| Clip              | A video of the visuals with the music, recorded live.                                           |
| `?for=developers` | The address that adds developer settings.                                                       |
