# Visualizer is free, open source and offered on a public website

## Context and Problem Statement

The product needs a clear answer to who may use it, copy it and build on it, and where people find it.

## Considered Options

1. Free to use, open source under the Apache 2.0 license, offered at a public website.

Only this option is recorded.

## Decision Outcome

Chosen option: "Free, Apache 2.0, public website", because the project is personal and non-commercial and invites outside authors to extend it.

### Consequences

- Good, because anyone can use it with no account or payment, and anyone can study, fork and extend it.
- Bad, because there is no paid tier to fund heavier features; everything must run on the visitor's own computer.

### Confirmation

The repository carries the Apache 2.0 license, and the site opens straight into the studio with no sign-up.

## More Information

- Confidence: Stated (license, site address); Inferred (non-commercial, from the private package manifest and the absence of any pricing)
